## 💼 Featured Projects

### 🧠 CodeAtlas — RAG-Based Codebase Intelligence
A retrieval-augmented system that lets you query a codebase in natural language and get accurate, context-aware answers.
- Tree-sitter AST chunking across 20+ languages, hybrid retrieval with FAISS + pgvector
- **100% Precision@10**, ~8.75s average query latency, indexed 106 chunks across 33 files
- Next.js frontend, Flask backend, HuggingFace `all-MiniLM-L6-v2` embeddings, Groq Llama 3.3 70B for generation

`Next.js` `Flask` `FAISS` `pgvector` `HuggingFace` `Groq` `Tree-sitter`

---

### 🔁 DSA Recall — Spaced-Repetition DSA Platform
A full-stack platform for retaining data structures & algorithms knowledge using spaced repetition tuned for coding practice.
- SM-2 spaced-repetition algorithm adapted with DSA-specific weighting
- Covers 18 DSA topics and tracks 7 distinct mistake types per problem
- Judge0 for code execution, Redis for caching, Groq Llama 3.3 70B for AI assistance, plus a Chrome extension

`React` `Vite` `Node.js` `Express` `PostgreSQL (Neon)` `Prisma` `Redis` `Judge0` `Groq`

---

### 🌾 KrishiCare — AI-Driven Agri-Tech Platform
An agriculture platform combining crop recommendation, rainfall forecasting, and plant disease detection in one product.
- Crop recommendation via Random Forest — **99.3% accuracy** across 22 crop classes
- Rainfall forecasting via a stacked ensemble model — **R² = 0.81, MAE = 35.96mm**
- Plant disease detection using a CNN, deployed Flask backend

`React` `Flask` `Scikit-learn` `Random Forest` `CNN`
